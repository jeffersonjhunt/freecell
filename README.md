# One Off FreeCell

FreeCell for iPhone, iPad and Mac, by [One Off Endeavors](https://oneoffendeavors.com): free, with
no ads, no accounts and no tracking. SwiftUI, one shared rules engine (`Packages/FreeCellEngine`),
one adaptive board.

It began as a copy of [One Off Solitaire](https://github.com/jeffersonjhunt/solitaire) 1.1 and
shares its patterns: the app shell, card styles, dialogs, win animations, Top 10 and Game Center,
and the build and release tooling. The rules and the board are FreeCell's own (see `spec.md`).

## Building

Everything builds from the command line on a Mac with Xcode; the project is generated by
XcodeGen (`tools/xcodegen`) from `project.yml`.

    make build        # the Mac app
    make test         # engine tests + the app's unit tests on the Mac
    make uitest       # UI tests on the Mac
    make help         # everything else, including archive, upload and testflight

Signing uses your team ID in `.devteam` (gitignored); App Store Connect access comes from
`~/.config/appstoreconnect/api.env`.
